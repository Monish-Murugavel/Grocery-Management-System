# 🛒 Grocery Billing API (FastAPI + SQLite)

A lightweight Grocery Management & Billing API built using FastAPI and SQLite.  
No external database setup required — runs completely locally.

---

## ✨ Features
- Add and list products
- Add and list customers
- Generate bills with multiple items
- Credit system:
  - Uses existing credit first
  - Earns 5% credit on paid amount
- SQLite database (no server needed)
